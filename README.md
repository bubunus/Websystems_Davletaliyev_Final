# RecipeBook — Django Web Application

A recipe-sharing platform built with **Django** and **SQLite**.

## Quick Start
```bash
pip install django
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```
Visit http://127.0.0.1:8000/
